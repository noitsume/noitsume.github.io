# Patch 1 — Tuning Notes

Perubahan revisi ini fokus pada penyempurnaan visual setelah audit layar:

- intensitas spreading light dark mode dinaikkan sekitar 25%;
- grain global dinaikkan sekitar 10%;
- kolom foreground kiri dan kanan diberi soft panel/well tanpa border keras;
- lebar shell desktop dikalibrasi ulang agar kolom kiri dan kanan lebih lurus di bawah cone light;
- ukuran beberapa container diperbesar: hero, rail cards, system cards, mobile note, sidebar items;
- mobile/tablet breakpoints disesuaikan agar proporsi baru tetap stabil.

Tidak ada perubahan pada arah visual utama, warna dasar, atau struktur komponen Patch 1.

- lebar shell desktop diperluas lagi agar main content lebih stretch dan panel kiri/kanan lebih pas berada di bawah sorot lampu;
- panel kiri/kanan dibuat sekitar 5% lebih transparan.
